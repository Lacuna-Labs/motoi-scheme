Motoi Scheme — 5 unified themes

one theme switch flips every surface: terminal · REPL · docs · renderer. red reserved for booleans.

Motoi Dusk
default (dark)
(begin
  (animation/clear!)
  (motion/move-to (list 'star 0 0) (list 9 0))
  (let loop ((n 0))
    (if (< n 5)
        (begin (animation/tick) (loop (+ n 1)))
        (length (animation/tweens)))))
(list (null? (animation/tweens))
      (number? (animation/tick))
      #t
      #f)
