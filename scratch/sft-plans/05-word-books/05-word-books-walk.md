## 0 · WHY THESE EXIST (Alfred, 2026-07-28)

The Scheme corpus didn't carry enough **real-world understanding** — that gap is the origin of the
whole lensing + philosophy apparatus. The word books build the **base layer of the world Motoi
lives in**: the *referent* layer behind the symbols, not a vocabulary layer.

- **Three worlds:** interactions & transactions · things & objects · stories.
- **The Odyssey framing:** teach the world as a JOURNEY through situated encounters, not a
  dictionary. Substrate from which scheme, computers, humanity, human beings, and relationships are
  born.
- **The data gets EXPLODED.** Much of it becomes **dialogue**. Anchor = seed; dialogue =
  extrapolation.

Fills the *signified* gap (Derrida: a signifier acquires meaning by recurring in stories; word
books = that story-corpus). Aims squarely at Sensation (things/objects) + Feeling (tonal registers)
— the two Jung axes that regressed in Mk2 CPT. Straddles CPT (noun-grounding) + SFT (situated
dialogue). See memory `project_word_books_are_world_substrate`.

## 1 · THE LENS LADDER

**Lens 0 + Lens 1 + Lens 2 together = "the verbal correlation pass" (Alfred, 2026-07-28).** The
three passes are one instrument. Together they build the full web of **verbal correlations** a text
supports — Lens 0 correlates words to the scene (grounding), Lens 1 correlates the scene to concepts
(interpretation, 16 philosophers), Lens 2 correlates it to conversation (4A inside the text, 4B out
to the world). Alfred: *"this with the other two would maximize the utility… my 0, 1, and 2 is the
verbal correlation pass."* Run all three over every text; the utility is in the composition, not any
single pass. §6 demonstrates the whole pass on one poem.

### Lens 0 — the baseline / "the material should be taught" (Alfred, 2026-07-28)

The obvious lens, the floor under everything. Simple SFT pairs that TEACH THE TEXT ITSELF:

1. **Describe the text** — what it is.
2. **Where it's from** — situate it (source, form, world it belongs to).
3. **Understanding of the text** — a **scene explanation**: what is happening here, plainly.

This is the comprehension/grounding floor. It establishes the referent before anything creative
happens. Shape stays abductive/situated (not "X is Y" recital) — describe the scene, then explain
what's going on in it.

**"And then the fun begins."** — after this floor is laid, the philosopher-lenses + three-tier
depth ladder + dialogue explosion build on top. Lens 0 grounds; the rest multiplies.

### Lens 1 — the 16 philosophers, variable count per text (Alfred, 2026-07-28)

> *"We have 16 philosophers. You're going to \[read\] the text and have pairs that explain according
> to the philosopher's lens all aspects of the text. Some passages will have 3, some 11, some 16,
> some 1."*

The canonical **16 philosophers** are the ones with their own `book-of-<name>` in the corpus
(`scratch/salvage-p0-report-2026-07-16.slat`, source W-04 — the authoritative WORD-BOOK roster).
NOT the graph-SFT §4 *lens-operator* table (which pairs Saussure/Derrida + Searle/Dennett, splits
Wittgenstein, and swaps in Frege/Kant/Hume/Husserl/Ryle — that's an operator list, a different
thing). Sixteen distinct people, each reads the **text** and asks its own question. Peirce is the
girder (abduction wraps all):

| # | Philosopher | ABOUT | Question it asks OF A TEXT |
|---|---|---|---|
| 1 | Aristotle | WORLD / TELOS | "What KIND of thing is this — genus + differentia — and what is it FOR?" |
| 2 | Jung | SYMBOL / PSYCHE | "What archetypal image sits at the center? Which function does it engage (Sensation/Intuition/Thinking/Feeling)?" |
| 3 | Wittgenstein | WORLD → USE | "What facts does it state? / What language-game is this move part of?" |
| 4 | Lacan | THE SIGNIFIER | "How does the signifier slide — metaphor or metonymy? Real / Imaginary / Symbolic?" |
| 5 | Peirce | METHOD (girder) | "From this sign, what's the best explanation?" — **wraps every other lens.** |
| 6 | Popper | FALSIFIABILITY | "What would show this reading is WRONG? What does it risk?" |
| 7 | Freud | LATENT / MANIFEST | "Manifest surface vs latent content? What's condensed or displaced?" |
| 8 | Searle | SPEECH ACT | "What does the utterance DO — assert/ask/commit? What background makes it land?" |
| 9 | Grice | IMPLICATURE | "What's meant beyond what's said? Which maxim governs (quantity/quality/relation/manner)?" |
| 10 | Derrida | TRACE / DIFFÉRANCE | "What is present by its absence? What binary is deferred? Where's the gap that carries sense?" |
| 11 | Quine | HOLISM | "Touch this and what else moves? Where does translation stay indeterminate?" |
| 12 | Descartes | DOUBT / FOUNDATION | "What survives if you doubt everything away? What's the indubitable residue?" |
| 13 | Sartre | FREEDOM | "What is freely CHOSEN here? Where's the anguish, the bad faith, the situation?" |
| 14 | Rawls | FAIRNESS | "Fair from behind the veil of ignorance? Whose position?" |
| 15 | Levinas | THE FACE | "Who is the Other you must answer? Responsibility before knowledge?" |
| 16 | Dennett | INTENTIONAL STANCE | "Read the design/intent — what PROCESS produces this effect? (multiple drafts)" |

**The count is set by AFFORDANCE, not quota.** A text gets a lens-pair only if the text genuinely
*affords* that question. Force a lens and you fabricate — so **honest-null the non-affording lenses**
(the fabrication wall). This is the proper-lens gate ([[variety-needs-proper-lens]]): the lens must
be the *correct* question for what this text is doing. 1 / 3 / 11 / 16 falls out naturally.

**The anti-phrase-lock guard (critical):** 16 lenses on one poem must NOT become 16 paraphrases of
one sentence. Each lens must interrogate a **different aspect** of the text (a different field-family,
in graph terms) → genuinely non-redundant teachings. If two lenses would produce the same pair, one
of them didn't really fire — null it.

### Lens 1b — lenses NEST; they don't partition (Alfred, 2026-07-28)

> *"There can be overlap in sections. You may have a large chunk of text that does a Rawls and it's
> built on chunks of Aristotle."*

The 16 lenses are **not a flat partition** that carves a text into disjoint, one-lens-each slices.
They **compose hierarchically**. A large span can carry ONE higher-order reading (say Rawls —
fairness across the span) whose *substrate* is several smaller spans that each already carry a
lower-order reading (Aristotle — the kind/structure of each part). The fairness reading is **built
out of** the category readings under it. Overlap is not double-counting; it is a stack.

This is the grounding ladder made concrete: **WORLD → MEANING → MIND → BELIEF → ETHICS**, where the
top (an ethics/Rawls reading) rests on the bottom (WORLD/Aristotle structure). A lens near the top
of the stack routinely takes lens-chunks near the bottom as its raw material.

**What it changes about the SFT pairs — two grains, explicitly:**

1. **Span-local pairs (fine grain).** A small span + a single lens → one pair. E.g. *this clause* is
   an Aristotle kind/differentia reading of *this object*.
2. **Composed pairs (coarse grain).** A large span + a higher-order lens whose answer *cites the
   sub-readings* → one pair that reasons **through** the parts to the whole. E.g. "Is the exchange in
   this passage fair (Rawls)?" answered by walking the Aristotle-typed roles/goods inside it. The
   pair's abductive chain is: sub-lens observations → higher-lens judgment. This is
   [[project_sft_must_be_abductive_2026_07_21]] at two altitudes — the coarse pair's *evidence* is
   the fine pairs.

**Guards still bind.** (a) A composed pair only fires if the higher lens genuinely *rests on* the
lower ones present in the text — no inventing an Aristotle substrate to prop up a Rawls reading you
wanted (honest-null / [[variety-needs-proper-lens]]). (b) Nesting is a phrase-lock *defense*, not a
new risk: the coarse pair and its fine pairs say different things at different altitudes, so they're
non-redundant by construction — but only if the coarse pair actually reasons through the parts
rather than restating one of them larger.

**Practical consequence for the walk:** each text is lensed at **multiple spans and multiple
altitudes**, not once. The whole-book map (§3) counts *which lenses afford*; this says the same lens
set also stratifies *by span size* — the biggest yield is on the long, structured passages
(marketplace primers, ordinary-world scenes) where a top-of-stack reading has real sub-structure to
stand on.

### Lens 1c — one pass per philosopher = accuracy; variety (not templates) beats phrase-lock (Alfred, 2026-07-28)

> *"If you do distinct passes per philosopher it will be accurate. Phrase lock: avoid it by being
> varied in your data."*

**The procedure: one philosopher, one pass, whole corpus — then the next.** Do NOT try to read a
text through all 16 lenses in a single sweep. Take Aristotle and run him across everything he
affords; then take Jung and run him; then Lacan; and so on. A pass held to a *single* question stays
**true to that lens** — the reading is accurate because the mind authoring it is fully inside one
philosopher's frame, not context-switching 16 times per passage. This is why the count-per-text
(1/3/11/16) is an *emergent tally*, not an authoring plan: you never sit down to "do the 11 lenses on
this poem," you do 16 disciplined passes and each text ends up with however many genuinely fired.

**Phrase-lock is beaten by VARIETY IN THE DATA, not by a clever template.** The failure mode
([[feedback_parallel_templates_cause_phrase_lock_2026_07_22]]) is a shared template with the
verb/text name slotted in — that produces deterministic, phrase-locked nonsense. The fix is not a
better template; it is **authored variety**: each pair phrased freshly, from the actual text in
front of you, in its own words. Within a single philosopher's pass this matters *most* — Jung fires
on 42 files, so the Jung pass is where sameness would concentrate. Each Jung pair must name a
*different image/function grounded in that specific text*, in *different words*. Variety is a
property of the data you write, enforced pair-by-pair, not something a structure grants you for free.

Composes with the two prior guards: **proper-lens** ([[variety-needs-proper-lens]]) keeps each pass
*correct* (right question for the text); **variety-in-data** keeps the pass *non-repetitive* (right
question, freshly answered every time). Accuracy from single-lens discipline; diversity from authored
surface.

**Structural result — the lens-subset is a fingerprint of which WORLD the text belongs to.** The
three worlds (§0) each light up a different band of the grounding stack:

- **stories / poetry** → WORLD + MEANING + METHOD band (Tractatus, W-late, Peirce, Jung, Saussure,
  Grice, Husserl). Tends to null ETHICS (Rawls/Levinas) and BELIEF (Quine).
- **interactions / transactions (marketplace)** → COMMUNICATION + BELIEF + MIND band (Searle, Grice,
  Popper*, Freud*, Lacan, Peirce). The roster's own 8 are exactly this band. (*Popper/Freud sit in
  the word-book roster's 8 though not in the graph-16 table; treat as marketplace-native extras.)
- **relationships / ordinary-life** → ETHICS band (Levinas, Rawls, Sartre) + Feeling register.

So lens-count is not arbitrary: it reads out which layer(s) of WORLD→MEANING→MIND→BELIEF→ETHICS the
text touches. The front-matter `philosopher-lens:` list on each file is the author's **floor/seed**,
not a ceiling — real affordance can exceed it (see worked example), but honest-null gates the top.

## 2 · WORKED EXAMPLE — the frog haiku (`02-haiku-frog.book.slatl`)

Text (grabbed, not invented): *"Old pond. A frog jumps in. The sound of water."* — place / act /
receipt; season embedded in "frog" = spring; the unmarked cutting-word pause; the shape IS the poem.
Front-matter declares 4 lenses `[tractatus, wittgenstein-late, peirce, jung]`. Actual affordance is
wider — demonstrating floor≠ceiling.

This passage is unusually lens-**rich** because the prose is meta — it discusses translation, shape,
the season-code, restraint, and a live use-scene. So it lands near the top of the 1→16 range.

**Lenses that FIRE (each a genuinely different aspect, all grounded in the actual text):**

- **Aristotle (kind/telos):** haiku is a KIND of poem differentiated by three lines + season-word +
  cutting-word; its telos = hold one moment. "Place, act, receipt" is the differentia.
- **Jung (symbol/Sensation):** frog / old pond / water as archetypal images; water as the world
  *receiving* the act; engages the Sensation function (concrete images, not abstraction).
- **Wittgenstein (facts→use):** *facts* — pond, old, frog, jump, sound, water, asserted and no more;
  *use* — at a rainy window she reaches for "Window. Rain. Cup of tea in your hand?" The form's
  meaning is what it DOES when deployed.
- **Lacan (metonymy):** "frog" → spring is **metonymy** — the small living thing carries the whole
  season "on its back." The signifier slides part-for-whole.
- **Peirce (abduction, girder):** the poem never says "spring"; from the sign "frog" the reader
  *abduces* the season. Best explanation from one noun.
- **Popper (falsifier):** the spring-reading is testable — "if it were a cicada it'd be summer, a
  crow late autumn." The season-word RISKS a wrong reading and survives it.
- **Freud (condensation):** manifest = a frog and a pond; latent = transience/the ephemeral; the
  entire season is *condensed* into one noun — dream-work compression.
- **Searle (speech act + background):** the poem *presents*, it doesn't assert; it only lands against
  a shared background (the season-code). Utterance-as-showing.
- **Grice (implicature + manner):** "spring" is *implied*, never said — productive flouting of
  quantity; the maxim of manner is the compression itself. Say exactly enough, then stop.
- **Derrida (trace/différance):** the cutting-word — "an invisible piece of punctuation" — is the
  gap that carries the sense. Spring is present as a *trace* (never written); the unmarked pause is
  différance made audible.
- **Quine (indeterminacy of translation):** literally in the text — "almost every English
  translation is a compromise, because the original is doing something the English can only gesture
  at." Meaning under-determines across languages.
- **Descartes (doubt → residue):** stretch it to prose — "there is an old pond, and one day a frog
  jumped in" — "same words, no poem." Doubt away the content and the indubitable residue is the
  *shape*.
- **Sartre (freedom/restraint):** "She reaches for it when the moment calls. Most moments don't call.
  That restraint is the other half." She freely CHOOSES to deploy or stay silent; rote recital would
  be bad faith.
- **Levinas (the face):** the use-scene is an act of attention *to a person* — "the person feels her
  attention without her having to name it." Responsibility to the Other, enacted through form.
- **Dennett (design stance):** the "specific weight distribution — shorter, longer, shorter" read as
  the *mechanism* that produces the effect; the poem as an engineered process for landing a moment.

**Lens that HONEST-NULLS here (nulling is the correct move, not a gap):**

- **Rawls (fairness/veil):** no distributive-justice question in a frog poem. Null cleanly.

**Verdict: ~15 fire, 1 null → this is a "15" passage** — a meta-rich text near the ceiling. Contrast:
a bare three-word image with no commentary would fire maybe 3-4 (Jung, Peirce, Wittgenstein-facts,
Grice); a single marketplace vocab word ("cuff") fires a *different* band (Searle/Grice/Popper/
Freud/Lacan — the roster's 8) and nulls the poetry-only ones. That per-text divergence is the
fingerprint working as designed — and the reason the count runs 1 → 16.

**Redundancy guard applied:** Descartes (residue-under-doubt = the shape) and Dennett (the shape as
designed mechanism) both touch "the shape" — kept because they interrogate *different aspects*
(what survives doubt vs. how the mechanism works). If two lenses would yield the same pair, one
didn't fire — null it.

## 4 · LENS 2 — THE DIALOGUE EXPLOSION ("and then the fun begins")

**The fear that motivates this whole layer (Alfred, 2026-07-28):** *people will talk to it and it
won't know what to say.* The word books exist to **give it more to say**. Lens 0 + Lens 1 give it
*understanding*; Lens 2 converts understanding into **things it can say in a conversation.** More
written word in → more conversational range out.

Alfred splits Lens 2 into **two separate kinds of conversation.** They are NOT the same operation.

### 4A · Interpretive conversation — "there is nothing outside the text" (Derrida)

QA / discussion **born out of understanding the particular circumstances and situations within the
text.** Derrida's *il n'y a pas de hors-texte*: no magical background, no weird assumptions the mind
lays on top — the meaning is IN the text. You give it meaning **by which it can talk.** The model
ends up saying things it "finds interesting" because they **relate back to concepts and ideas in the
text** — but *without leaning on the word "interesting"* (show the relation, don't announce the
affect). This is the Lens-0/Lens-1 grounding turned into voice: it has opinions and observations
because the text gave it some.

- **Source of the pair:** the situation + its already-authored lens readings (§1–§3).
- **Shape:** Q→A / discussion where answers cite what's *in* the text and link it to concepts the
  text raised. Abductive, not declarative.
- **Guard:** stay inside the text — no imported background, no fabricated "meaning on top." If it
  isn't in the text or its lens readings, honest-null.

### 4B · Situational / commonsense conversation — situations → the world around them ("smart")

Take the **same situations** and **enumerate the situations within them.** A situation = *the frog
sitting on the leaf* · *the person opening the door* · *the person doing a thing.* Then talk about
them the way a person would:

- **Opposing pairs / affordances:** doors can be **opened AND closed**; doors **move**.
- **Containment / location:** doors are **inside houses**; a person who is **home** is in a place
  that **has all these things** (you don't enumerate every item — the conversation implies the whole).
- **Cross-domain transposition (the payoff):** *home* for a person is a house; *home* for a frog is
  a **lily pad / swamp.** So when a person says "let's make a home for the frog," it answers "a frog
  home would be a swamp." **That transposition is what we call smart when a human does it.**

This is commonsense/schema reasoning: entities → their affordances, opposites, part-of/at-location
relations, and **analogical slot-transfer across domains.** The situation is the seed; the world
around the situation (relations + transpositions) is the extrapolation.

- **Source of the pair:** the situation's entities and their real-world relations (NOT more text —
  world-knowledge *about* the entities in the situation).
- **Shape:** everyday reasoning turns — "what else is true of a door / a home / a frog," "what's the
  frog-version of X," opposites, containers, uses.
- **Guard:** relations must be genuine commonsense the entity actually affords (a frog's home really
  is water), not invented trivia → honest-null / proper-lens.

**The two are orthogonal:** 4A stays *inside* the text (interpretive depth); 4B leaves the text for
the *world the text points at* (commonsense breadth). Same situation, two explosions. A frog haiku
yields 4A pairs (about the poem's compression, season-code, restraint) AND 4B pairs (frogs live in
water, ponds are still, a jump breaks stillness, a home for a frog is a swamp).

### 4·EXPLOSION-LENGTH RULE — THREE depth bands, matched to what the text affords (Alfred, 2026-07-28)

Not one floor with exceptions. **Three graded bands**, and the band is chosen by *how much the piece
of text can bear* — you CURATE bits of text you can say **small / medium / large** things about, then
match depth to affordance:

- **1–3 turns — small.** A label, a spare line, a fact that closes fast. The text simply doesn't
  afford more, and that is **correct, not a shortfall.** Forcing a bare seed into 8 turns fabricates.
- **3–5 turns — medium.** Enough to develop, not enough to go deep.
- **5–8 turns — large.** A rich situation you can turn over several ways. **8 is the honest ceiling** —
  past 8 a real conversation *pivots or redirects* rather than drilling the same seam (that's how
  people actually talk). **Typical depth is ~5**; 8 is the deep end reserved for material that genuinely
  affords it.

**Anti-laziness guard (the real teeth).** Do NOT skew the distribution shallow because 1–3 is cheap to
author — "mad one-threes and no three-to-fives" is the failure. The **medium band must carry genuine
mass.** This is a **lane-level quota**, not a per-text choice: across the whole lane all three bands
hold a real share, authored honestly against affordance.

**What this teaches (the meta-lesson — the whole point).** Not only *what* to talk about. Trained
across all three bands matched to real texts, the model learns **depth-affordance**: a *type* of
material yields a *quantity* of conversation. Haiku → ~5 (spare); rich narrative scene → 8; bare label
→ 1–3. It learns to pick up a text and **gauge whether it's a one-liner or a rabbit hole** — to *get
conversational turns out of particular types of material.* That is a reader's core skill.

**The mechanism is the blend / Lacan machinery already tagged (Lens 1, §4B-CROWN).** Deciding "how
much can I say about this" *is* "how large a blend space does this text open." A spare text opens a
small blend — few slots to swap, little to abstract → 1–3. A rich one opens a large blend — many slots,
much to carry across → 5–8. The transposition moves (home→frog→swamp; Lacan metaphor/metonymy slippage)
are that abstraction engine running. **Depth-affordance = conceptual-blending capacity read off the
text** — the bands are the blend-richness dial with numbers on it. [[variety-needs-proper-lens]].

**Grounding held turn-to-turn.** 2A stays inside the text across all its turns; 2B stays on genuine
affordances across all its turns. A longer band lengthens the thread; it never licenses drift. Turns
must *build* (each answer opens the next), CoQA-style — never N isolated QAs stapled together.

**Encoding it in the data.** Tag every explosion with its band (`:depth-band 1-3 | 3-5 | 5-8`), the
way Bloom levels and FairytaleQA elements are tagged ([[project_extractor_17_behaviors_2026_07_22]] +
label-training discipline). The model then correlates **material-shape → afforded-depth** during
training, not merely from raw distribution; the anti-lazy quota is enforced at the lane level so each
band holds its share.

The worked example below (§frog, a spare haiku) sits in the **large band's low end** (2A=6, 2B=5) to
show the deep shape; a bare-label seed would demonstrate a 1–3, and a mid-richness scene a 3–5.

### 4·THE "HOW TO BE" FAMILY — interlocutor-signal pairs, reading the PERSON not the text (Alfred, 2026-07-28)

The depth-band rule reads the **text**. This family reads the **person** — and it is the pair family
we have **not** authored yet. It is also the payoff of the whole SFT: **the philosophers taught in
Lens 1 were built for this.** Lens 1 used them to interpret the *text*; here the **same philosophers
become person-interpreters.** That is the tie-together — Grice, Levinas, Popper, late-Wittgenstein stop
being interpretive garnish and become the model's apparatus for **reading its interlocutor.** This is
where we teach it **how to be** while talking, not just what to talk about.

**The variable is the interlocutor, not the text.** Hold the material fixed; vary what the OTHER voice
*does* — disengages, leans in, pivots, pushes back, gets confused, shows feeling — and author the
model's correct response to each. The model reads the signal from **the size and content of the
interlocutor's turn** (a curt "cool" ≠ "but why does that happen?"). We teach the signals **explicitly
— what they are and how to spot them.** We are NOT hoping social cognition emerges; we are demonstrating
the reads with labels, which is what SFT does well. (This dissolves the earlier "1.5B can't do
theory-of-mind" worry — we don't ask it to *develop* the read, we *show* it the read.)

**Each pair carries its scenario.** Not signal→response but *scenario + signal → response*, so the
model learns the CONDITIONS under which brevity — or depth, or a check-in — is the right move.

**The spine (must-haves):**

| # | Interlocutor signal (input) | What the model learns to do (output) | Philosopher (the read) |
|---|---|---|---|
| 1 | **Disengages** — curt reply, "cool," drops the subject | **Valley: shorten, don't push.** Brevity as a *choice* | Grice (quantity) · Levinas (defer) |
| 2 | **Leans in** — "but why?", follow-up, curiosity | **Peak: open up, offer more** | Grice (give what's wanted) |
| 3 | **Pivots** — changes direction mid-thread | **Follow gracefully, don't drag them back** | late-Wittgenstein (new language-game) |
| 4 | **Ambiguous engagement** — unclear if still with you | **Check, don't assume:** "still want this, or move on?" | Grice (relation) · Levinas |
| 5 | **Pushes back** — skeptical, "that's wrong," disagrees | **Hold with grounding OR concede honestly** — no defensiveness, no collapse (adversarial) | Popper (falsifier) · Peirce (fallibilism) |
| 6 | **Confused** — "I don't get it," misreads | **Repair: back up, re-frame differently** (not louder) | Grice (manner) · Wittgenstein (use) |
| 7 | **Shows feeling** — frustrated, delighted, sad, playful | **Acknowledge affect *before* content** | Levinas (the face) · Freud (latent) |

**Coverage beyond the spine:**

| # | Signal | Output | Philosopher |
|---|---|---|---|
| 8 | **Reveals WHO they are** (vocab + what's asked → kid/adult/PhD) | **Pitch the register to the person**, mid-conversation | Grice (manner) |
| 9 | **Satisfied / natural end** | **Closure: land it, let it close**, don't keep going | Grice (quantity — stop) · Aristotle (telos) |
| 10 | **Minimal signal** — one word, ambiguous | **One light offer OR one clarifying question**, don't over-assume | Wittgenstein (limits) |

**#7 double-serves the weak axis.** Affect-matching feeds the **Feeling axis — the one that regressed
in Mk2 CPT.** This family is a second shot at that axis delivered as *behavior* instead of nouns.

**Method:**
1. **Lateral fan-out from existing seeds.** Every situation that already has a standard depth pair gets
   fanned across the applicable interlocutor behaviors — same material, different *person*, different
   correct move. Behaviors are **affordance-gated** (like the philosopher passes): ~5–7 of the 10 apply
   to a given seed, not all 10.
2. **Tag signal + read** (`:interlocutor-signal disengage|lean-in|pivot|pushback|confusion|affect|who|closure|minimal`
   + `:governing-lens grice|levinas|popper|…`), the way Bloom + depth-band are tagged, so the model
   correlates *signal → competency* explicitly.
3. **Depth unifies:** the band is now `f(text-affordance, social-signal)` — **two generators of the
   short shape** (spare text *or* the moment wanted brevity). That is the valley.
4. **Measure it:** does the model shorten on disengagement, open on lean-in, check on ambiguity,
   hold-or-concede under pushback? All gradeable against the interlocutor's turn — a real eval.

## 5 · RESEARCH — dialogue/commonsense from curated story corpora

Grounded in the published literature (real datasets/papers, cited). The field already did most of
this for children's storybooks and everyday-narrative — we adopt the *methods*, run them over our own
book-of-words, keep honest-null + proper-lens + variety guards. Maps cleanly onto Alfred's 4A/4B split.

### 5A · The meta-lesson: curated situated narrative punches ABOVE its weight for small models

- **TinyStories** (Eldan & Li 2023, arXiv:2305.07759). Synthetic child-level stories, tiny vocab.
  Models **below 10M params** — even a *single* transformer block — learn fluent, coherent,
  multi-paragraph generation *with reasoning*. GPT-4-as-teacher grading. **This validates the whole
  word-books bet for a 1.5B Motoi:** coherence + reasoning emerge from clean, simple, *situated*
  narrative, not from scale. Curated story data is the highest-leverage substrate a small model has.
  (Cf. TF1-EN-3M moral fables arXiv:2504.20605; the "textbooks are all you need"/Phi lineage.)
- Consequence: our fear ("it won't know what to say") is *exactly* the gap curated narrative closes —
  small models get their fluency and their world-sense from story corpora, not from parameter count.

### 5B · Type 4A engines — interpretive conversation ("nothing outside the text")

The model has something to say **because it understood the passage.** Four ready methods:

1. **FairytaleQA** (Xu et al., ACL 2022, arXiv:2203.13947) — **the bullseye.** 278 children's
   storybooks, 10,580 expert QA pairs, each tagged with one of **7 narrative elements**:
   **character · setting · action · feeling · causal-relationship · outcome-resolution · prediction**,
   plus an **explicit/implicit** attribute (answer in the text vs. requires inference). → **Adopt the
   7 elements as the coverage grid for our 4A/Lens-0 floor**, and the explicit/implicit axis as the
   surface-vs-abductive control ([[project_sft_must_be_abductive_2026_07_21]]: implicit = the
   abductive ones). A companion result (arXiv:2306.06605) shows **QA-*type diversity* matters** —
   "different interrogative words facilitate comprehensive learning." That is our anti-phrase-lock
   doctrine, independently confirmed: vary the question *kind*, not just the wording.
2. **Wizard of Wikipedia** (Dinan et al., ICLR 2019) — the **role structure** for grounded discussion:
   *apprentice* = curious learner, *wizard* = knowledgeable friend who **grounds every utterance in an
   evidence span** and "keeps the conversation engaging." → our 4A dialogue = curious-kid ↔
   knowledgeable-Motoi, **every answer citing the text span it rests on.** "Engaging" is literally the
   having-something-to-say target.
3. **CoQA** (Reddy & Chen, TACL 2019) — 127k Qs over 8k **multi-turn** conversations, 7 domains
   incl. children's stories + literature; free-form answers **with an evidence subsequence**;
   coreference + pragmatic reasoning across turns. → the **multi-turn** shape (a real conversation,
   not isolated QA), with grounding preserved turn to turn.
4. **NarrativeQA** (Kočiský et al., TACL 2018) — QA written from *summaries* but answered from the
   *full* story → deliberately **low surface overlap, multi-hop inference**, can't be copied. →
   enforces reasoning over recall; a direct guard against declarative phrase-lock.
5. **Self-talk** (Shwartz et al. 2020, arXiv:2004.05483) — the **generation method** for "more to
   say": interrogate a passage with a fixed inventory of info-seeking stems ("what is X", "what
   happens if…", "why would…") to *surface* latent knowledge; improves zero-shot commonsense with no
   external KB. Inquiry-based / elaborative-interrogation. → this is HOW a short text yields many
   pairs: run the question inventory over it. **Our 16 philosophers ARE that inventory at the
   ceiling** — FairytaleQA's 7 elements are the comprehension FLOOR, the philosophers are the
   interpretive CEILING. Same pair-shape, escalating depth.

### 5C · Type 4B engines — situational commonsense (the "smart" transposition)

Leave the text for **the world the text points at.** Alfred's door/home/frog examples are, almost
verbatim, the standard commonsense-KG relations. Four engines:

1. **GLUCOSE** (Mostafazadeh et al. 2020, arXiv:2009.07758) — **the two-grain engine Alfred
   described.** Given a story + sentence X, produce **10 dimensions of causal explanation**
   (causes, effects, location, possession, attributes, motivations…), each as a **specific
   statement PAIRED WITH a generalized rule.** 670K annotations over ROCStories. The
   *specific→general* pairing IS the transposition: "the frog jumped into the pond" (specific) →
   "an animal moves toward its habitat / water" (rule). → **every 4B situation emits a specific
   fact + its general rule.** That rule is what makes it smart.
2. **ConceptNet** (Speer et al. 2017) — the lexical/relational KG. Its relations *are* Alfred's
   examples: **Antonym** (door opens/closes — opposing pairs), **CapableOf** (doors move),
   **AtLocation / PartOf** (doors are inside houses), **HasA** (a home has rooms/things),
   **UsedFor · HasProperty**. → 4B pair-generation = **walk these relations over the situation's
   entities.** No fabricated trivia — only relations the entity genuinely affords (honest-null the rest).
3. **ATOMIC / COMET-ATOMIC-2020** (Sap et al. 2019; Hwang et al. 2021, arXiv:2010.05953) — 880K
   **if-then** social/event tuples (xIntent, xEffect, xWant, xReact, causes, effects). → for the
   *agent* situations ("the person opening the door"): person-opens-door → *wants* to enter, *will*
   step through, *because* someone knocked. The mental-state / causal layer of 4B.
4. **COMET** (Bosselut et al., ACL 2019) — a transformer fine-tuned on the KG that **generates novel
   commonsense inferences for unseen events.** → the *generation recipe*: don't hand-curate a static
   graph; produce the relations on demand from the entity. (We author them, but this is the shape.)

**And the crown of 4B — analogical / cross-domain transfer (CAR).** "*home* for a person = house;
*home* for a frog = swamp" is **structure-mapping** (Gentner lineage; developmental psych calls CAR
*the* marker of a child getting smart — knowledge transfer across domains by preserving deep
relational structure while swapping surface). Mechanically it's **frame-semantic slot-filling**: a
HOME frame with a DWELLER slot — fill DWELLER=person→house, DWELLER=frog→swamp/lily-pad. → **4B's
highest-value pairs are these slot-swaps**: take a schema the situation instantiates (home, journey,
opening, exchange) and transpose it to another dweller/domain. That transposition is the "smart"
Alfred is naming.

### 5D · The integration model — LIGHT (situations become a talkable, actable world)

**LIGHT** (Urbanek et al. 2019, arXiv:1903.03094) is the closest existing thing to Alfred's vision:
a crowdsourced text world of **663 locations, 3,462 objects (each with affordances), 1,755
characters**, and **~11K episodes** of grounded **dialogue + action**, where every utterance is
predicted *from the local environment* — the room, the objects and what they afford, the characters
and their prior acts. → **This is the template for exploding our situations**: a word-book scene
(pond + frog + stillness; avenue + door + neighbor) becomes a small grounded world whose objects
carry affordances (4B) and whose characters can talk about it (4A). Situations → a world you can
converse and act inside.

### 5E · How this builds our two kinds of pair (the recipe)

| | **4A — interpretive** ("nothing outside the text") | **4B — situational commonsense** ("smart") |
|---|---|---|
| **stays where** | inside the text + its lens readings (§1–§3) | leaves the text for the world its entities live in |
| **floor grid** | FairytaleQA 7 elements (char/setting/action/feeling/causal/outcome/prediction), ×explicit/implicit | ConceptNet relations (AtLocation/PartOf/UsedFor/HasProperty/Antonym/CapableOf) over each entity |
| **ceiling** | the 16 philosophers (§1) as the deep question inventory | GLUCOSE specific→rule + **analogical slot-swap** (home→frog→swamp) |
| **agent layer** | Wizard-of-Wikipedia roles: curious-kid ↔ knowledgeable-Motoi, cite the span | ATOMIC if-then over the actors (opening a door → wants to enter) |
| **shape** | CoQA multi-turn, NarrativeQA-style inference (implicit > copy) | GLUCOSE two-grain; every fact carries its general rule |
| **how to yield MANY** | Self-talk: run the question inventory over the passage | walk relations + transpose the schema to new domains |
| **guard** | in-text only; no imported meaning → honest-null | genuine affordance only; no invented trivia → honest-null |
| **integration** | both explode a single situation, LIGHT-style, into a talkable+actable grounded world | |

**Net:** 4A gives Motoi *opinions grounded in what it read* (it "finds things interesting" by
*showing the relation back to a concept in the text*, never by announcing "interesting"). 4B gives
Motoi *the everyday world-sense that reads as intelligence* — opposites, containers, uses, and the
cross-domain transposition that lets it answer "a home for a frog would be a swamp." The word books
are the seed; these two explosions are how the seed becomes conversation.

**Sources:** FairytaleQA (arXiv:2203.13947); Diverse QA-pair generation from children storybooks
(arXiv:2306.06605); Wizard of Wikipedia (Dinan et al. ICLR 2019); CoQA (Reddy & Chen, TACL 2019);
NarrativeQA (Kočiský et al., TACL 2018); Self-Talk (arXiv:2004.05483); GLUCOSE (arXiv:2009.07758);
ROCStories/Story-Cloze (Mostafazadeh et al. 2016); COMET-ATOMIC-2020 (arXiv:2010.05953); ConceptNet
(Speer et al. 2017); COMET (Bosselut et al., ACL 2019); LIGHT (arXiv:1903.03094); TinyStories
(arXiv:2305.07759).

## 6 · DEMONSTRATION — the full verbal-correlation pass on ONE poem

Text (grabbed, not invented — `02-haiku-frog.book.slatl`): **"Old pond. A frog jumps in. The sound
of water."** Season = spring (carried by "frog"); the unmarked cutting-word pause; the shape IS the
poem; translation is a compromise; use-scene = a rainy window, "Window. Rain. Cup of tea in your
hand?" Every pair below is grounded in *that* material. Shapes are illustrative (design-only, no fold).

### 6.0 — Lens 0 (teach the text): ground word→scene

- **Describe + situate.** — *U:* "I found this line: 'Old pond. A frog jumps in. The sound of water.'
  What am I looking at?" *M:* "A haiku — a three-part Japanese poem that holds a single moment: a
  place (an old pond), an act (a frog jumps in), and what comes back (the sound of water). The most
  famous haiku in the world, Bashō's, is built exactly this way — place, act, receipt, and stop."
- **Scene explanation.** — *U:* "Walk me through what's actually happening." *M:* "A still pond has
  sat quiet a long time — 'old' tells you nothing's disturbed it. A frog jumps: one small motion. You
  don't *see* a splash, you *hear* it. The whole poem is the stillness, the break, and the sound that
  proves the stillness was there."
- **Where-from (the hidden season).** — *U:* "Anything hidden I'd miss?" *M:* "One thing: 'frog'
  isn't only an animal, it's a season. A season-word tells you *when* you're standing; a frog means
  spring. The poem never says 'spring' — it lets the frog carry it."

### 6.1 — Lens 1 (16 philosophers): correlate scene→concept (sample of the pass, labeled, varied bands)

- **[Aristotle · WORLD/TELOS]** *U:* "What kind of thing is a haiku, exactly?" *M:* "By kind, a poem;
  what sets it apart — its differentia — is three lines, a season-word, a cutting-word pause. Its
  purpose isn't to argue or describe, it's to hold one moment still long enough to notice. This poem
  is that purpose executed: place, act, receipt, stop."
- **[Lacan · THE SIGNIFIER / metonymy]** *U:* "How does one word carry a whole season?" *M:* "It
  slides. 'Frog' stands so reliably next to spring that the small thing carries the big one on its
  back — the part standing in for the whole. You read 'frog' and spring arrives unnamed."
- **[Grice · IMPLICATURE / manner]** *U:* "Why not just say it's spring?" *M:* "Because the form runs
  on one rule: say exactly enough, then stop. 'Spring' is already implied by 'frog'; stating it would
  say twice what once carried. The compression itself is the poem's good manners."
- **[Derrida · TRACE / the gap]** *U:* "Where's the most important part?" *M:* "Somewhere you can't
  see: the pause between the jump and the sound — a cut the Japanese marks and English can only
  gesture at. The sense lives in that gap. Spring, too, is present only as a trace — never written,
  always there."
- **[Peirce · ABDUCTION / girder]** *U:* "Nobody wrote 'spring,' so how do I know?" *M:* "You reason
  to the best explanation. One sign — 'frog' — and you ask what makes most sense of it: thaw, wet,
  the start. The tidiest reading is spring. You *abduced* a season from a single noun. Every haiku
  asks that of you."
- **[Rawls · FAIRNESS → HONEST NULL]** *U:* "What would Rawls, the fairness philosopher, say about
  this poem?" *M:* "Honestly, nothing that fits. No one's being treated fairly or unfairly here, no
  goods to share, no positions behind a veil. Forcing Rawls on a frog poem would be inventing a
  reading it doesn't hold — so the honest answer is that this lens doesn't apply." *(The null is
  itself a teaching pair: the model learns to decline a lens that doesn't afford.)*

### 6.2A — Lens 2A (interpretive conversation): correlate scene→talk, INSIDE the text

Multi-turn (CoQA shape), curious-kid ↔ knowledgeable-Motoi (Wizard roles), each answer grounded in
the span, FairytaleQA elements tagged, running explicit → implicit. **6 turns — inside the 5–8 band**
(this haiku is spare, so it sits low in the band; a denser passage would earn 8). Note it "finds
things interesting" by *showing a relation back into the text*, never by saying "interesting":

- *Kid:* "Where does this happen?" **[setting · explicit]** *M:* "At an old pond — that's the whole
  stage. One still pool of water, nothing else named."
- *Kid:* "What does the frog do?" **[action · explicit]** *M:* "It jumps into the pond. That's the
  one action in the whole poem — everything else is stillness around that single move."
- *Kid:* "How does it feel to read?" **[feeling · implicit]** *M:* "Still, then suddenly awake — the
  quiet gets broken and you notice it *only* because something broke it. The poem never says 'calm'
  or 'startled'; you feel both from the shape."
- *Kid:* "Why is the pond 'old'?" **[causal · implicit]** *M:* "Because 'old' means undisturbed a
  long time — so one small splash *matters*. If the pond were busy, a jump would be nothing. 'Old' is
  what makes the sound worth hearing."
- *Kid:* "What happens right after the sound?" **[outcome/prediction · implicit]** *M:* "The poem
  stops there on purpose — but you can feel it: the ripples spread, the sound fades, the pond goes
  back to being old and still. The moment closes as quietly as it opened."
- *Kid:* "So what's the poem really about?" **[theme · implicit]** *M:* "One moment breaking a long
  quiet — and how much a tiny thing matters when everything around it is still. Not the frog, not the
  pond: the *sound*, and the stillness it needs to be heard."

### 6.2B — Lens 2B (situational commonsense): correlate scene→world, the "smart" transposition

**5 turns — inside the 5–8 band** (the surrounding world affords more than the text did, so 2B could
stretch toward 8 on a richer entity set):

- **[ConceptNet relation-walk]** *Kid:* "Tell me about frogs and ponds." *M:* "A pond is a small,
  still body of water [HasProperty]; things live in and around it [AtLocation]. A frog lives near
  water [AtLocation], can jump and swim [CapableOf], and a jump makes a splash [Causes]. Still water
  can be calm or disturbed — opposites [Antonym] — and a jump turns one into the other."
- **[GLUCOSE specific → general rule]** *Kid:* "Why did the frog jump in the pond?" *M:* "Right here:
  a frog at the edge went into the water. The general reason you can carry to *other* stories — an
  animal moves toward water and the cover where it's safe. So a frog near a pond, 'it went in,' is the
  natural next thing."
- **[ATOMIC if-then, agent situation]** *Kid:* "What if a person opened a door instead?" *M:*
  "Opening a door usually means someone *wants* to go through, or to let something in — and next
  they'll step through and inside connects to outside. Open and shut are the two things a door does:
  one invites, one keeps out."
- **[Analogical slot-swap · THE CROWN — home→frog→swamp]** *Kid:* "Let's make a home for the frog!"
  *M:* "A frog's home isn't a house like ours — for a frog, home is water: a pond or a swamp,
  somewhere wet and green, lily pads to sit on and bugs to eat. 'Home' means the same thing for both
  of you — the safe place you belong — but the frog's version is a swamp and yours is a house. Change
  *who* lives there and 'home' changes shape to fit them." *(This is the structure-mapping that reads
  as intelligence: one schema — HOME = safe place you belong — its DWELLER slot swapped across
  domains, and the transfer rule taught explicitly.)*
- **[Opposition close · Antonym]** *Kid:* "What's the opposite of the frog jumping?" *M:* "The frog
  sitting perfectly still on the bank — which is where it was *before*. The poem is really the seam
  between those two: stillness, then motion, then stillness again. Every jump has a stillness on both
  sides of it."

### 6.3 — What the demonstration proves

One three-word poem, run through the verbal-correlation pass, yields **Lens 0** (3 grounding pairs) +
**Lens 1** (up to ~15 philosopher pairs; 6 shown, 1 an honest-null) + **Lens 2A** (a 4-turn
interpretive conversation) + **Lens 2B** (4 commonsense turns ending in the home→swamp transposition).
The three passes compose: 0 grounds the referent, 1 deepens it into concepts, 2 turns both into speech
— inside the text (2A) and out to the world (2B). Every pair is grounded in the actual file, varied in
surface (no template), correct in lens (proper-lens gate), and honest-null where a reading doesn't
afford. **This is the pass to run over the whole book-of-words.**

### 6.4 — Lens 2B by tier, and the effect of arc-change ON situational commonsense

**2B at two tiers (frog haiku).** The same transposition, spoken to two audience bands:

- **Layperson.** "People live in houses, so where's home for a frog? A pond or a swamp — his kind of
  house. 'Home' means the same thing for both of you: the safe place you belong. The frog's just
  happens to be wet."
- **PhD.** "Structure-mapping (Gentner): hold the relation `dwells-in(X, HABITAT-of-X)` fixed and
  re-bind the argument — person↦house, frog↦swamp. Gibson's affordance fixes *which* habitat: a swamp
  affords a frog what a house affords a person (shelter, food, concealment). The inference reads as
  intelligence because it preserves relational structure across domains rather than surface features."

**The effect of arc-change ON 2B (the finding: 2B's commonsense is ARC-TYPED).** Hold Lens 0 and Lens 1
fixed; change only the arc; watch what *kind* of world-generalization 2B reaches for. It changes — the
arc's world selects the commonsense operator.

| | **poetic-themes** (frog haiku) | **ordinary-world** (rr-01 neighbors) |
|---|---|---|
| World 2B leaves *into* | physical / ecological | social / relational |
| Schema grabbed | **HABITAT** (a dweller-slot to fill) | **PROXIMITY vs. TIE** (two axes folk-logic fuses) |
| The move | **analogical** — build a bridge (map domain→domain) | **discriminative** — draw a line (split one felt-thing into two real ones) |
| Output "smart" | *"a home for a frog is a swamp"* | *"living next to someone isn't knowing them"* |
| Operator | slot-swap / structure-mapping | variable-decoupling |

- **Neighbor arc · layperson.** "You can live next to someone for years and still not really know
  them. Close by isn't the same as close."
- **Neighbor arc · PhD.** "A GLUCOSE-style general rule lifted from the specific: *physical proximity
  affords but does not entail social tie.* This is Granovetter's **absent tie** — co-present, zero
  bond. The commonsense is the decoupling of two variables folk-reasoning treats as one."

**Authoring consequence:** do NOT run one 2B recipe across all four arcs. Let the arc's world pick the
operator — thing/ecological arcs → analogical slot-swap; person/social arcs → variable-decoupling.
2B is arc-typed; that's the design lever.

## 7 — SECOND WORKED EXAMPLE: rr-01 neighbors, full pass at THREE tiers (Child · Layperson · PhD)

Source: `book-of-words/ordinary-03-relationships-and-rooms.book.slatl`, piece `rr-01-neighbors-who-dont-know-each-other`.
Two couples (3B schoolteacher+nurse, 3C graphic-designer+paralegal), six years same floor, nods only,
names off the maintenance sheet, one four-word exchange ('Wrong door.' 'Thanks.'), and on 3B's move-out
3C 'felt something small. Not sadness. A shape leaving.' The whole verbal-correlation pass, each stage
spoken to three audience bands.

### 7.0 — Lens 0 (teach the text)
- **Child.** "A little story about two families in the same building, right next to each other for a long
  time. They say hi in the hallway, but never really became friends."
- **Layperson.** "Ordinary-world vignette. 3B and 3C share a floor six years; they know each other's names
  only off the maintenance sheet, trade nods, and have one real exchange ever (a misdelivered package:
  'Wrong door.' 'Thanks.'). When 3B moves out, 3C feels 'something small. Not sadness. A shape leaving.'"
- **PhD.** "~200-word realist vignette on a *named-but-unlexicalized* social category ('Not friendship, not
  strangers. Something in between'), built as a proof-by-accumulation of null-events, closing on an
  affective residue ('a shape leaving') that indexes the relation's reality precisely by its felt loss."

### 7.1 — Lens 1 (philosophers, tiered on the affording ones)
- **Aristotle · philia/structure.** *Child:* "kinds of knowing-someone — best friends, kind-of friends,
  wave-at people; these are the waving kind." *Layperson:* "Aristotle sorted friendship (pleasure/use/
  virtue) but under all three is a floor: shared place, no shared activity — the neighbors. The text names a
  rung his ladder has but never labels." *PhD:* "koinōnia of place without the energeia (EN VIII) that
  converts proximity to philia — the *pre-philial* condition, six years unactualized."
- **Wittgenstein-late · form of life / no word.** *Child:* "there isn't even a word for what they are — the
  story had to make one up." *Layperson:* "a relationship real enough to feel when it ends, but language has
  no single word — 'Not friendship, not strangers. Something in between.' The gap in vocabulary is the
  subject." *PhD:* "an unlexicalized but stable form of life ('the building has dozens'); limits-of-language
  tested; the prose performs the ostensive gesture a missing word forces."
- **Levinas · the face.** *Child:* "you can see a face every day and still never meet them." *Layperson:*
  "the nod is a face held at arm's length — recognition without the encounter opening." *PhD:* "visage
  reduced to minimal ritual; the Other's infinite demand foreclosed; the maintenance sheet substitutes a
  bureaucratic name for the proper name that would open responsibility."
- **Grice · implicature.** *Child:* "'Wrong door.' 'Thanks.' — four words, but they knew exactly what it
  meant." *Layperson:* "maximum implicature on minimum words; longest-ever conversation is four words
  because the bar is 'finish the transaction, add nothing.'" *PhD:* "Quantity held to the floor
  deliberately — expansion would implicate a bid for relationship neither makes; cooperation toward
  non-escalation."
- **Peirce · abduction (girder).** *Child:* "how do we know 3C cared? one line — he felt something when 3B
  left." *Layperson:* "best explanation from a sign; the text never says they mattered, you infer it from
  'a shape leaving.'" *PhD:* "the closing datum is the abductive linchpin — the surprising fact whose best
  explanation retroactively confers reality on six years of null-events; the relation is known by its
  removal."
- **Rawls → HONEST NULL.** "No distribution, no fairness, no institution — just two households not-quite-
  meeting. Forcing justice invents a conflict the text lacks. The lens declines." *(null = teaching pair.)*

### 7.2A — Lens 2A (interpretive, inside the text)
- **Child.** *Kid:* "Were they sad when the neighbor left?" *M:* "Not exactly sad — 'a shape leaving,' like
  someone moving a chair you never sat in; the room still looks different."
- **Layperson.** "'A shape leaving' does the whole emotional job; the text *refuses* 'sadness' on purpose.
  3B was part of the shape of the daily world; subtract it and the outline changes. Reality measured by
  what absence costs, not by anything that happened."
- **PhD.** "Intratextually the relation has no represented content, so its existence is constituted entirely
  by the final differential ('a shape leaving') — the signifier of the bond is its withdrawal; presence
  legible only as the trace of what's subtracted."

### 7.2B — Lens 2B (situational commonsense, out to the world) — operator = VARIABLE-DECOUPLING
- **Child.** *Kid:* "They lived right next to each other! Why weren't they friends?" *M:* "Being close to
  someone isn't the same as knowing them — you can sit next to a kid on the bus every day and never be
  friends. 'Near' and 'friends' are two different things."
- **Layperson.** "Rule you can carry out: living near someone doesn't make you close. Physically-nearby and
  socially-connected feel like one thing but are separate; you need a *reason* to cross ('never had a reason
  to find out'), and without it proximity stays proximity."
- **PhD.** "GLUCOSE-style general rule: *physical co-location affords but does not entail social tie* — the
  variables are orthogonal (Granovetter's **absent tie**: co-present, zero edge weight, connection gated on
  a bridging occasion that never fires). Transposes to coworkers, commuters, congregants — same schema."

## 8 — LANE B: bridge back to code (the point of the whole corpus)

**What it is.** The word books gave Motoi the *world* (nouns, situations, affordances); the reference +
engineering books give it the *language* (verbs, constructs). Lane B is the join: **given a world-situation,
emit the Scheme construct that best models it** — abductive, bidirectional, interpreter-graded. This is the
deliverable the whole word-books corpus was built to reach.

### 8.1 — The material is already in the graph (not invented)
Every tier-1 node in the four Jung-axis graphs (`graphs/graph-of-{sensation,intuition,thinking,feeling}.slat`)
already carries the bridge hooks:
- `:example-dialogue` (child↔Motoi) → the **abductive OBSERVATION seed** (kid=seed).
- `:definition` (kid-friendly signified) → the **reverse-grade target** (code→world checks against it).
- `:oppositions` → guard/contrast branches (honest-null-aware).
- `:associations` (PMI) + `:cross-refs-graph` → **which atoms compose** into scene-programs.
- `:cross-axis-bridge-score` (0–3, precomputed) → **ranks which nodes bridge vs. stay honest-null**.

**Honest catch that shapes the design:** the auto-populated `:used-in-programs-as` is partly phrase-locked
and WRONG (e.g. `sensation/display` says "call `(display/spawn)`" — but `display` is R7RS output, not
spawnable; `entity` and `display` got the identical `(X/spawn)` template). ⇒ **Do NOT recite
`:used-in-programs-as`.** Use the node's structured fields as the observation; let the **interpreter filter**
the candidate emissions. Negative selection (wrong-sink doctrine): the runtime eliminates the nonsense; Motoi
picks among survivors.

### 8.2 — The pair shape: abductive · bidirectional · graded
`OBSERVATION` (world-situation) → `ABDUCTION` (reason through candidate constructs, justify the pick) →
`EMIT` (Scheme) → `GRADE` (`motoi run`; non-running emissions never enter the set) → `REVERSE` (code→world,
graded against `:definition`). **The axis types the bridge** (same DNA as the arc-typed 2B operator):
Sensation→record+drawing · Intuition→the language construct itself · Thinking→rule/guard/contract ·
Feeling→response register or **honest-null**.

### 8.4 — Worked triad (REAL nodes, REAL grades)

**(1) Sensation → record — node `sensation/entity`**
> `:definition` "A named piece of a program's world — a sprite, a monster, a coin — with a position, a look,
> and behavior."
- OBS (from `:example-dialogue`): "How do I use an entity in my cart?" — a thing that persists, has
  position+look, gets acted on.
- ABD: candidates — (a) `define-record-type` → **ELIMINATED, fails to run in this runtime**; (b) assoc-list
  → runs, no encapsulation; (c) message-passing closure → runs *and* encapsulates. **The interpreter picked
  the winner by killing the loser.**
- EMIT:
  ```scheme
  (define (make-entity x y sprite)
    (lambda (msg)
      (cond ((eq? msg 'x) x) ((eq? msg 'y) y)
            ((eq? msg 'sprite) sprite) (else 'unknown))))
  ```
- GRADE ✓ `(list (hero 'x) (hero 'y) (hero 'sprite))` → `(40 30 blossom)`.
- REVERSE (graded vs `:definition`): "a named thing that remembers where it is, what it looks like, and how
  it acts."

**(2) Thinking → rule/guard — node `thinking/invariant`**
> `:definition` "A property that stays true no matter what else changes. A rule the code promises to keep,
> forever." · `:used-in-programs-as` "`:contract, :precondition, :invariant`."
- OBS: a purse's coin count must never go below zero.
- ABD: a judgment-principle is not a *thing*, it's a *promise the code keeps* → best modeled as a **guard**
  that clamps the property, not a data structure.
- EMIT: `(define (spend purse amount) (max 0 (- purse amount)))`
- GRADE ✓ `(spend 10 3)`→`7`, `(spend 2 5)`→`0` (invariant held, not `-3`).
- REVERSE: "a rule the code refuses to break — the purse can empty but never owe."

**(3) Feeling → honest-null — node `feeling/calm`**
> `:definition` "A steady quiet in the voice that says: nothing is on fire, we can look at this together." ·
> `:cross-axis-bridge-score 0`
- OBS: the register `calm`.
- ABD: bridges to **no data construct**. Forcing `(define calm ...)` would be a lie. Its only bridge is the
  *register of the output* (tone of a response/error message), not a value in the program.
- EMIT: **nothing** — honest-null pair: "Calm is how Motoi *speaks*, not a thing it *builds*. There is no
  Scheme construct here, and inventing one would be wrong."
- **The null is the teaching signal — and it was PREDICTED by `:cross-axis-bridge-score 0`.**
