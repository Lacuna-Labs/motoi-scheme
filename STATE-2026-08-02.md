### The 262, by where they live

~166 are in `src/reader.js` alone:
- no radix or exactness prefixes at all — `#x11` reads as a *symbol* (95)
- no `|vertical bar|` symbols (26)
- string escapes silently wrong — `"\a"` yields the letter `a`, not alarm (9)
- `read` lacks `#;` datum comments and `#| |#` block comments (12) — note these
  *do* work at file top level, so there are two code paths and one has drifted
- `#u8` reader silently substitutes 0 for anything it can't parse:
  `'#u8(#x41 #x42 #x43)` → `#u8(0 0 0)`, no error (8)

13 are `syntax-rules` hygiene in `src/macro.js`, reproduced identically by both
suites — the classic referential-transparency case returns `inner` where R7RS
§4.3.2 requires `outer`. One variant leaks a raw JavaScript TypeError.

The rest are in `lib/base/r7rs-small.js`: exactness inferred from integrality
rather than represented (14, plus 6 `write` round-trip failures), optional
start/end arguments ignored (6), `raise-continuable` doesn't resume (9),
quasiquote defects (8), and small clusters below 5 each.

Also: `string-set!` / `string-fill!` / `string-copy!` are absent (49 failures) —
strings are immutable. Classified unimplemented rather than wrong, and possibly
a deliberate teaching choice, but R7RS §6.7 requires them.
